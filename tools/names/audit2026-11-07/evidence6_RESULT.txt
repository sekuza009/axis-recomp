Findings, written into the comments
  - The menus' free camera (freeCam_keys, freeCam_mouseLook, freeCam_stepLeft / Right and the g_freeCam* globals,
    g_slotCams, g_watchChatOpen ...) never runs: its only caller is the menus' dispatch for screen 9999, and
    menu_frame runs only while the screen is not 9999 (app_frameByScreen). The match's free camera is free_camera.
  - Script command 26 (MESSAGE) stops the game with "invalid speaker / text" with any of the game's data: nothing
    fills Stage.speakers / texts. The test map reached the message ring only with indices that wrap round to its
    own text (32-bit address arithmetic).
  - Command 27 (a scene path) lasts at most one frame: nothing reads the .scp file, and stage_advanceScenePath
    clears scriptMode in the same frame, so Scene.scriptMode is never seen non-zero.

Still unreached (evidence6_still_unreached.txt), and why
  - one-frame input flags (g_rightClick, g_mouseWheel*, g_mouse3Down, Scene.playAsked ...): set and cleared within a
    frame; the 250 ms sampler misses them (their handlers ran: the function trace)
  - lock-on (Stage.lock*, Actor.aimTime / lockAnim / homedOn / beepTimer): the rocket arena's rockets are no
    lock-on weapon; needs a weapon with a targeting time held on an enemy
  - the Ladder / game-server paths (35): need DServer sessions with answers it does not send (out-of-date notice,
    a join that times out, a ranking request in the room)
  - Korean glyphs: the Korean player name was set, but no Korean text was drawn in the screens visited
  - the 80 "unreachable" by design, and the free-camera globals above
